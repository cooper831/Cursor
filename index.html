Momcozy 线框原型

进入 momcozy-app-scene-prototype/index.html

若浏览器提示「该网页无法正常运作」、「无法访问此网站」或一直转圈，多半是没有正在运行的本地 HTTP 服务，或地址里的端口写错（例如之前开过 8765，现在却在开 8766）。

请在终端执行（路径按你本机为准）：

cd "momcozy-app-scene-prototype"
./serve.sh

终端若出现 Address already in use，表示该端口已被其它程序占用（常见是之前开过的 http.server 没关）。可直接运行上面的 ./serve.sh，脚本会自动换一个空闲端口；或手动指定端口：./serve.sh 8800，再用浏览器打开终端里打印的地址。

若不用脚本，也可：python3 -m http.server 8765，然后打开 http://127.0.0.1:8765/index.html（端口需与命令一致）。

若用 VS Code / Cursor 的 Live Server，请把站点根目录设为文件夹 momcozy-app-scene-prototype，或从本页点进上面的链接，避免 CSS、图片路径 404。
