---

## 1. 背景与问题

首页底部「商品推荐」当前信息密度偏卖场化，**商业感强、趣味性弱**，与用户所处**孕期 / 产后育儿**等阶段的情境关联不够直观。

本需求在**不牺牲转化路径**的前提下，通过**场景化卡片 + 轻交互轮播**，提升**相关性、可读性与点击意愿**，并与品牌「Cozy」系列场景叙事对齐。

---

## 2. 目标与成功指标

### 2.1 产品目标

- **场景化**：以用户旅程阶段组织内容，而非纯 SKU 列表。
- **低压迫感**：首屏卡片弱化价格、促销与强 CTA，以**情境 + 探索型 CTA**为主（详情页再承接交易信息）。
- **可扫读**：主标题、副标题行数可控，避免版面撑破或信息堆叠。
- **可交互验证**：提供可滑动原型，便于评审与用研走查。

### 2.2 成功指标（建议上线后补齐埋点）

- 卡片区域 **CTR**（点击 CTA 或卡片任一热区）。
- 横向轮播 **滑动渗透率**（是否浏览非首卡）。
- **首卡曝光到点击**时长分布。

---

## 3. 用户与场景

### 3.1 用户分群（与 App / 画像一致）

- **孕期**：待产、睡眠与身体舒适相关需求。
- **产后 / 哺乳期**：喂养效率、穿戴式吸乳、节律恢复。
- **产后修复**：舒缓、护理与身体恢复。
- **外出育儿**：便携、收纳与出行信心。
- **日常育儿**：柔软、安全与夜间稳定感。

### 3.2 内容场景（与品牌「Cozy」五段旅程一致）

在「为你精选」入口卡之后，依次覆盖：

1. **Cozy Pregnancy** — 舒适待产
2. **Cozy Feeding** — 舒适喂养
3. **Cozy Recovery** — 舒适修复
4. **Cozy Outing** — 舒适外出
5. **Cozy Parenting** — 舒适育儿

首卡为**算法 / 运营精选入口**（Picked for you），与五段场景共同构成 **6 张卡片**。

## 4. 功能需求

### 4.1 模块结构


| ID  | 需求描述                                                                                     | 优先级 |
| --- | ---------------------------------------------------------------------------------------- | --- |
| F-1 | 模块顶部展示区块标题：**Recommended for you**（与英文产品环境一致；若独立中文版可映射为「为你推荐」）。                          | P0  |
| F-2 | 卡片横向排列，支持**左右滑动**切换；**禁止**底部圆点 / Tab / Banner 式分页锚点。                                     | P0  |
| F-3 | 当前卡居中，**左右露出相邻卡边缘**，暗示可滑动。                                                               | P0  |
| F-4 | 每张卡包含：**场景图占位区**、**场景标签（Pill）**、**主标题**、**副标题**、**个性化 CTA**；**不包含**左下角「根据记录推荐」等推荐来源类弱文案。 | P0  |
| F-5 | 首卡与 5 张 Cozy 场景卡**文案全部为英文**（若落地中文站，另起本地化 PRD / 词条表）。                                     | P0  |
| F-6 | CTA 为**短文案 + 右箭头**，每张卡**不同**以增强趣味与点击动机（见第 6 节词条表）。                                       | P0  |
| F-7 | 点击 CTA 进入**场景详情 / 列表承接页**（具体路由由业务方配置）；原型阶段可用占位弹窗。                                        | P1  |
| F-8 | **桌面端**：轮播区域支持**滚轮纵向映射为横向滚动**、**鼠标拖拽**、**键盘左右键**（焦点在轮播容器内）。                              | P1  |
| F-9 | **演示用机壳**（可选）：iPhone 14 Pro Max 风格外框 + 灵动岛 + Home 条，内容区为真实可滑轮播（仅演示，非生产强制）。               | P2  |


### 4.2 交互与手势

- **触摸**：原生横向滚动 + `scroll-snap` 吸附至卡片中心。
- **拖拽**：鼠标拖拽时临时关闭 snap，松手后恢复（避免拖拽卡顿）。
- **误触**：拖拽距离超过阈值时，抑制同一次操作对 CTA 的误点。

### 4.3 布局与适配

- 轮播轨道宽度与 **padding 计算基准一致**（全宽 breakout，避免 `100vw` 与父级 `max-width` 错位导致无法滑动或 snap 异常）。
- 卡片宽度随容器使用 **容器查询（cqw）**，保证在机壳内比例稳定。

## 5. 视觉与信息架构规范

### 5.1 风格关键词

- 参考 **Apple 式**：大圆角、浅灰底 `#F5F5F7`、白卡、轻阴影、系统蓝链接色、留白充足。
- 占位图：**斜纹灰底 + 图标 +「Scene placeholder」**（可替换为真实场景摄影）。

### 5.2 卡片区域比例（对齐参考线框）


| 区域    | 规范                                                     |
| ----- | ------------------------------------------------------ |
| 顶部场景图 | 约占卡片总高的 **60%**                                        |
| 下方信息区 | 余下约 **40%**：自上而下为 Pill → 主标题 → 副标题 → 底部 CTA 行          |
| 整卡高宽比 | 高度与宽度联动，约 **H ≈ W × 1.38**，并设合理 `max-height`，避免过小屏裁切严重 |


### 5.3 文案行数与省略


| 元素   | 规则                                                            |
| ---- | ------------------------------------------------------------- |
| 主标题  | 最多 **2** 行，超出 **省略号**；支持长词折行（`word-break` / `overflow-wrap`）。 |
| 副标题  | 最多 **2** 行，超出 **省略号**；规则同主标题。                                 |
| Pill | 单行，尽量短。                                                       |
| CTA  | 单行，短词组（建议 ≤ 18 英文字符量级）。                                       |


### 5.4 字体层级（当前原型）

- 主标题：**17px**、Semibold、行高约 **1.35**。  
- 副标题：**14px**、Regular、灰色次级色。  
- Pill：**12px**、胶囊浅灰底。

## 7. 非功能需求

- **无障碍**：轮播 `role="region"` + `aria-label`；卡片标题使用语义化 `h2`。
- **动效**：尊重 `prefers-reduced-motion`（减少平滑滚动等）。
- **性能**：首屏卡片数量固定为 6，图片懒加载（接真实 CMS / CDN 时补充）。

---

## 8. 验收标准（Acceptance Criteria）

1. 可见 **6** 张卡，顺序与第 6 节表格一致，**全英文**。
2. **无**底部圆点 / Tab 式分页条。
3. **无**卡片左下角推荐来源类文案。
4. 主标题、副标题在极端长文案下均**不超过 2 行**且显示省略。
5. 上图区约占卡高 **60%**，整卡比例与参考线框一致感通过设计走查。
6. 横向滑动在真机与桌面浏览器均可切换到相邻卡，且**邻卡有露出**。
7. 每张 CTA 文案**互不相同**，且与第 6 节一致或可配置为等价长度的新文案（需产品确认）。

---

## 9. 不在范围（Out of Scope）

- 真实商品价、券、库存与加购逻辑（由商详 / 结算承接）。  
- 个性化推荐算法实现与隐私合规评审（本 PRD 仅定义**展示与交互**）。  
- Android 非演示机壳的像素级还原。
