2
订阅中台 · 支持快速上线能力
能力层：准入门槛 → 付费产品标准化定义 → 多平台接入落地（三段式）

2.1接入前置条件（准入 Gate）

  • 功能用户价值验证（已上线 · 核心场景跑通）
  • 用户评价满意度（满意度 / NPS 达标）
  • 付费意愿度（WTP 调研 / 假墙点击率）

仅通过 Gate 的功能才可进入中台产品化（指标见第 5 层 5.1）

→

2.2付费产品定义（中台能力抽象）

  • 产品用户画像（人群 / 生命周期阶段）
  • 核心用户价值定义（卖确定性结果）
  • 付费功能与权益清单
  • 定价策略（档位/月年付/试用/促销/本地化）
  • 触发条件（硬件绑定/记录N天/额度/月龄/异常）
  • 合规（自动续费/退订/隐私/医疗声明/商店政策）
  • 履约与共享规则（家庭共享/降级/退订保留）
→

2.3订阅付费接入（落地动作）

  • 新订阅产品上线 / 已有产品扩充权益
  • 功能权益绑定（功能 ↔ 权益 ↔ 档位 映射）
  • 多平台配置（iOS / Google Play / Web · RC 统管）
  • 内外部推广位配置（站内 Paywall / 站外投放 / 私域）
  • 用户使用指引（Onboarding / 功能引导 / 客服话术）
3
Paywall 入口（依据 RevenueCat + 调研）
触点层：按「触发时机」归类的入口类型，形态从硬阻断到渐进式

硬阻断式

  • Onboarding 终点强制墙

高阻力 · 转化高但差评高 谨慎

渐进式 / 锁头图标 🔒

  • 功能旁挂锁，点击触发

成本最低 · 转化最高 推荐

上下文动态触发

  • 数据感知后主动弹卡（奶量异常→分析墙）

主动关怀 · 焦虑驱动转化最高

资产 / 到期墙

  • 试用到期、硬件赠送期到期

损失厌恶 · 温和保留历史

额度耗尽墙

  • 免费 AI 对话 3 次用完

先建依赖再设墙

里程碑 / 阶段墙

  • 宝宝月龄节点解锁新阶段

情感驱动 · 中等

升档墙

  • 家庭共享超员 / 专家连线

高 ARPU 权益

展示形态

  • 全屏 / 半屏卡片 / 内嵌按钮 / 弹窗 / Banner
4
用户触达（方式 · 特点 · 场景，依据 RC + 调研）
触达层：在用户需要时主动出现，覆盖 App 内 / Push / 生命周期 / 报告 / 硬件侧

App 内触达

  • 首页常驻智能卡片
  • 独立 AI Tab
  • Story 卡片 / 挂锁入口

特点：被动+主动并行 ｜ 场景：日常高频使用动线

推送 Push

  • 晨间报告
  • 异常告警
  • 月龄节点提醒

特点：主动 ｜ 场景：定时/事件驱动

生命周期消息

  • 邮件 / 站内信
  • 试用提醒 · 临期续费 · 退订挽留

特点：主动 ｜ 场景：订阅生命周期节点

报告型触达

  • 月度成长报告
  • 年度回顾

特点：情感化 ｜ 场景：续费决断强化

硬件侧触达

  • 开箱引导
  • 设备绑定时弹试用

特点：购买意愿最强时 ｜ 场景：软硬一体专属

触达原则

  • 主动型转化 > 被动型（Flo / Nanit 验证）
  • 数据感知触发 > 等待用户提问
